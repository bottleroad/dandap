# dandap (단답) 🤫

> **"불필요한 미사여구는 버리고, 기술적 팩트와 페이로드만 남긴다."**  
> [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)에서 영감을 받아 제작된 **한국어 맞춤형 초간결 개조식 브리핑 & 토큰 절약 스킬**입니다.

---

## ⚡ 왜 단답(dandap)인가?

1. **토큰 낭비 제거**: 인공지능의 "네, 확인해 드리겠습니다", "도움이 되었으면 좋겠습니다" 같은 의례적 인사말과 완곡어법은 매 호출마다 사용자 비용을 두 배로 만듭니다.
2. **터미널 가독성 극대화**: 엔지니어에게 필요한 것은 [결함 원인], [수정 내용], [다음 액션]뿐입니다.
3. **한국어 최적화**: 단순 번역 투가 아닌, 실무 개발팀의 개조식 보고 톤(`~함`, `~음`, `조치 완료`)으로 응답합니다.
4. **페이로드 100% 보존**: 코드, 파일 경로, CLI 명령어, 에러 메시지 원문은 단 1자도 왜곡/축약하지 않습니다.

---

## 🎛️ 스킬 모드 비교

| 구분 | 일반 모드 (Normal) | **dandap (단답)** | **chodandap (초단답)** |
| :--- | :--- | :--- | :--- |
| **명령어** | 기본 | `/dandap` | `/chodandap` (또는 `/dandap cho`) |
| **톤앤매너** | 친절하고 완전한 구어체 문장 | 간결한 개조식·명사형 종결 (`~함`, `~음`) | 단어/파편(Fragment) 나열, 어미 생략 |
| **답변 예시** | "확인해보니 토큰 만료 조건문에 버그가 있었습니다. `<`를 `<=`로 변경하여 수정했습니다. 서버를 재시작해 주세요." | `auth 미들웨어 토큰 만료 조건 오류 확인됨. < 연산자를 <=로 수정함. 재기동 필요.` | `인증 오류. < 대신 <=. 수정 완료. 재시작.` |
| **추천 상황** | 복잡한 개념 학습 및 설명 요구 시 | **일반 개발, 코드 리뷰, 기능 구현** | **긴급 디버깅, 모바일/좁은 터미널, 반복 루프** |

## 🚀 사용법 및 토글 제어

### 1. 활성화 (On)
* `/dandap`: 일반 단답 모드 활성화 (개조식 종결)
* `/chodandap` 또는 `/dandap cho`: 초극단적 파편 압축 모드 활성화

### 2. 종료 (Off)
다음과 같은 종료 의미를 가진 단어가 입력되면 즉시 원래 기본 말투로 복귀합니다.
* `/dandap 종료`, `/dandap 해제`, `/dandap 멈춤`, `/dandap 그만`, `/dandap stop`, `/dandap off`
* `/chodandap 종료`, `/chodandap 해제`, `/chodandap stop`
* `단답 종료`, `단답 해제`, `초단답 해제`, `일반 모드`, `normal mode`

## 📂 전역 스킬 등록 (Installation)

Antigravity 및 AI 에이전트 환경에서 어디서나 이 스킬을 호출할 수 있도록 글로벌 스킬 디렉터리에 심볼릭 링크를 생성합니다.

```bash
# dandap 스킬 링크
ln -s /Users/gil/workspace/my-skills/dandap ~/.gemini/skills/dandap

# chodandap 스킬 링크
ln -s /Users/gil/workspace/my-skills/dandap/chodandap ~/.gemini/skills/chodandap
```

등록 후 어느 대화 세션에서든 `/dandap` 또는 `/chodandap`을 입력하여 바로 사용할 수 있습니다.
